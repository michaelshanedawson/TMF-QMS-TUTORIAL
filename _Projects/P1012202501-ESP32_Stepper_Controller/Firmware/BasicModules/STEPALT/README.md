### Welcome to the ESP32 project kickstart folder!
* Change this file up with relevant info when the project compiles for the first time.
* The main.c file can be renamed, be sure to update the CMakeLists.txt file to reflect that change.
* Feel free to add header and their relevant *.C files but be sure to update the CMakeLists.txt file to reflect this addition.
* If pulled from the GIT repository, delete the .git folder and replace with the one for the actual project.
