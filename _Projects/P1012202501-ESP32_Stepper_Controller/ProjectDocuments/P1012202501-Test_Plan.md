---

### Purpose and Scope

**Purpose:** Define the testing requirements designed to validate the functional, performance, safety, and regulatory requirements for a modular development kit integrating an ESP32 micro-controller and a DRV8825 stepper motor driver.  
**Scope:** Applies to the ESP32 based DRV8825 stepper motor driver with RS-485 interface.

---

### Required Materials
* `P1012202501-01 Test Plan Log.xlsx` file located in `/ProjectDocuments/test-logs/` to store the results of the testing process.
* Schematic and BOM for the device.
* Fully assembled device(s) for testing.
* Bench top power supply capable of current limiting with the ability to deliver up to 30V @ 5A.
* Multi-Meter capable of resistance, voltage, current and temperature reading.
* Infrared temperature gauge.
* Thermocouples and materials to affix them to the PCB.
* Basic hand tools such as screwdrivers.
* Computer system with USB connectors and software to program the ESP32.
* Appropriate USB-C cable with power and data to connect to the PCB assembly.
* Terminal emulator software on PC capable of communication over serial UART interfaces. An example would be PuTTY.
* USB to UART interface cable such as an RS-232 FTDI assembly.
* USB to RS-485 adapter and two small lengths of wire for interfacing to the RS-485.
* Assembled and tested momentary pushbutton for limit and control input testing.
* Click PLC `pn here` with testing program `P1012202501InputTest` installed.
* The Click PLC should have the `pn here` discreet input/output module installed and working.
* Appropriate 4 wire, bipolar stepper motor.

### Initial Testing
#### Visual Inspection
* Test 1: Visually inspect the assembled board for any workmanship defects such as poor soldering or off-pad components following IPC Class II criteria. Store the results in the log file.

### Functional Requirements
#### These tests are verification only and are performed during the visual inspection. Refer the design schematics for additional verifications.
* FR-001: Does the design include an ESP32 with Wi-Fi and BLE capabilities?
* FR-002: Does the design include the Texas Instruments DRV8825 stepper motor driver IC with step, direction, and enable inputs?
* FR-003: Does the design support 12-24VDC input with integrated 3.3V and 5.0V regulation for logic circuits?
* FR-004: Does the design incorporate pluggable headers for the RS-485, control inputs, limit inputs, and motor outputs?
* FR-005: Does the design incorporate a USB capable interface for programming the ESP32?
* FR-006: Does the design incorporate test points for the power rails?
* FR-007: Does the design incorporate LEDs for visual indication of function or status?

### PCB Sub-System Testing and Verification
* SST 1: With the PCB assembly connected to the power supply set at 24VDC and the output enabled, connect the USB-C cable to the computer and the PCB assembly. Does the system recognize a newly connected serial port? This validates that the USB to UART bridge chip is operating properly and that the computer does detect an operational COM port.
* SST 2: Using the computer and ESP32 programming software, flash the `HelloWorld` firmware and validate that the system can program the ESP32 and that basic communication does happen over the UART interface. This test validates that the ESP32 can be programmed, boots and operates normally. May need to use the BOOT and ENABLE buttons on the PCB for the first ESP32 flashing.
* SST 3: Using the computer and ESP32 programming software, flash the `UARTFTDI` firmware. Connect the USB to FTDI adapter to the PC and to the PCB at J4 observing proper connector orientation. Load up PuTTY with these settings for the appropriate COM port, baud rate of 115200, 8 data bits, 1 stop bit and no parity. Upon reset or after pressing the EN button, this message should appear on the terminal: P1012202501 UART FTDI Interface Test Firmware.
-------------------
In the terminal window, type in the following: echo test
A response should be sent back that looks like the following:
Echo: test
If the response is successful, this is a pass condition and verifies that the UART interface is working properly.
* SST 4: Using the computer and ESP32 programming software, flash the `STATUSLD9` firmware to the ESP32. Observe the red LED D9 and verify that it is flashing at a rate of about 5 second intervals.
* SST 5: Using the computer and ESP32 programming software, flash the `RS485TEST` firmware. Connect the USB to RS-485 adapter to the PC and to the PCB at CN2 observing proper connections to A and B. Load up PuTTY and validate that basic bi-directional communication does happen over the UART FTDI (J4) interface.
* SST 6: Using the computer and ESP32 programming software, flash the `INPUTTEST` firmware. Install 1 jumper onto J2 and 1 jumper onto J3. This will connect the common circuits to the internal ground plane. Connect the test button unit wire #1 to the 24VDC power supply positive connection. Connect the #2 wire to CN3 terminal #1. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a single flash with a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN3.
* SST 7: Connect the #2 wire to CN3 terminal #2. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a double flash with an interval of 1 second and a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN3.
* SST 8: Connect the #2 wire to CN3 terminal #3. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a triple flash with an interval of 1 second and a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN3.
* SST 9: Connect the #2 wire to CN4 terminal #1. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a quadruple flash with an interval of 1 second and a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN4.
* SST 10: Connect the #2 wire to CN4 terminal #2. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a series of five flashes with an interval of 1 second and a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN4.
* SST 11: Connect the #2 wire to CN4 terminal #3. Check the status LED D9 to see if it is flashing. If it is not, press and hold the test button and observe if D9 is indicating a series of six flashes with an interval of 1 second and a delay of 2 seconds. If this test is successful, disconnect the #2 wire from CN4.
* SST 12: With the `INPUTTEST` firmware flashed to the PCB assembly, remove the jumpers on J2 and J3. Disconnect any wires presently tied to CN3 or CN4. Connect the test button #1 wire to the PLC power supply positive terminal block. Connect the #2 wire to the PLC X1 terminal. Connect the PCB assembly CN3 terminal 1 to the PLC Y1 output, the CN3 terminal 2 to Y2 output, the CN3 terminal to Y3 output and the CN3 terminal 4 to the PLC positive power supply. Connect the PCB assembly CN4 terminal 1 to the PLC Y4 output, the CN4 terminal 2 to the PLC Y5 output, the CN4 terminal 3 to the PLC Y6 output, and the CN4 terminal 4 to the PLC positive power supply. Verify that 24VDC is applied to the PCB assembly and that the PLC is also powered up properly. Place the PLC into `RUN` mode and wait a few seconds for it to settle. Press the test button and observe the PCB assembly status LED D9. The LED should follow a similar blink pattern as in the prior test but in sequence as each input is tested. Once testing is completed, set the PLC to `STOP` mode and power down. Power down the PCB assembly and disconnect from the PLC for next test phase.
* SST 13: Ensure that the bench top power supply is set to 24VDC and the current limit is set to at least 2A. Flash the PCB assembly with the `STEPPERTEST` firmware. Disable the power supply output then connect the motor A+ input to CN7 terminal 1, connect the A- input to CN7 terminal 2, connect the B+ input to CN7 terminal 4, and the B- input to CN7 terminal 3. Refer to the stepper motor documentation for proper input identification. Enable the power supply output and observe the stepper motor. It should rotate clockwise for about 30 seconds then stop and start rotating counter-clockwise for another 30 seconds then stop and repeat the cycle. If this is observed, the test is a success.
