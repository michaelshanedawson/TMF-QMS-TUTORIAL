### Product Test Plan

**Project:** ESP32 + DRV8825 Development Kit  
**Document ID:** P1012202501-Test_Plan.md
**Owner:** Project Design Lead  
**Version:** 1.0  
**Date:** 2025-12-15 

---

### Purpose and Scope

**Purpose:** Define the testing requirements designed to validate the functional, performance, safety, and regulatory requirements for a modular development kit integrating an ESP32 micro-controller and a DRV8825 stepper motor driver.  
**Scope:** Applies to the ESP32 based DRV8825 stepper motor driver with RS-485 interface.

---

### Required Materials
* `P1012202501-01 Test Plan Log.xlsx` file located in `/ProjectDocuments/test-logs/` to store the results of the testing process.
* Schematic and BOM for the device.
* Fully assembled device(s) for testing.
* Bench top power supply capable of current limiting with the ability to deliver up to 30V @ 5A.
* Multi-Meter capable of resistance, voltage, current and temperature reading.
* Infrared temperature gauge.
* Thermocouples and materials to affix them to the PCB.
* Basic hand tools such as screwdrivers.

### Initial Testing
#### Visual Inspection
* Test 1: Visually inspect the assembled board for any workmanship defects such as poor soldering or off-pad components following IPC Class II criteria. Store the results in the log file.
#### Initial resistance measurements
* Test 2: Using the multi-meter in resistance mode, check between TP1 (+3.3V) and TP 3 (GND) and verify that the resistance is greater than 5KΩ. If the measured value is below, stop and inspect the board for assembly issues that could cause a short or low resistance reading such as a solder bridge. If problem is not identifiable, elevate to direct supervisor for next steps.

#### Initial board power up testing
* Test 44: Set the bench DC power supply to 5V with a current limit of 100mA. Ensure that the power output is disabled. Connect the red positive output to CN1 Terminal 1 and the black negative output to CN1 Terminal 2. Enable the power supply output and check if the current limit trips. Also observe the assembled PCB for any electrical issues such as arcs or smoke. If any of the failure conditions arise, disable the power supply output and inspect the assembly for issues that could cause these issues. If the problem is not identifiable, elevate to direct supervisor for next steps.
* Test 45: Disable the power supply output. Set the output voltage to 24VDC and the current limit to 500mA. Enable the power supply output and check if the current limit trips. Also observe the assembled PCB for any electrical issues such as arcs or smoke. If any of the failure conditions arise, disable the power supply output and inspect the assembly for issues that could cause these issues. If the problem is not identifiable, elevate to direct supervisor for next steps.
* Test 46: With the power supply output enabled, configure a multimeter to DC voltage measurement and connect the negative lead to TP3 (GND) and the positive lead to TP1 (3.3V). Check and verify that the voltage output is positive 3.3V +/- 125mV. If any failure conditions arise, disable the power supply output and inspect the assembly for issues that could cause these issues. If the problem is not identifiable, elevate to direct supervisor for next steps.
* Test 47: With the power supply output enabled, configure a multimeter to DC voltage measurement and connect the negative lead to TP3 (GND) and the positive lead to TP2 (5.0V). Check and verify that the voltage output is positive 5.0V +/- 125mV. If any failure conditions arise, disable the power supply output and inspect the assembly for issues that could cause these issues. If the problem is not identifiable, elevate to direct supervisor for next steps.
